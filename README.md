# 走线等距

[简体中文](README.md) | [English](README.en.md)

用于嘉立创EDA专业版的 PCB 走线等距扩展。通过画布两点取区或读取选中走线，设置目标中心距，即可调整完整走线或独立线段；支持严格等距、兼容展开、自动识别铜层和推挤周围走线。

## 使用方法

1. 打开 PCB 文档，通过 **线段等距 → 调整选中线段间距** 打开面板。
2. 选择「完整走线」或「独立线段」，铜层默认「自动识别」。独立线段需要至少两条同层平行直线；完整走线会沿连接关系扩展目标。
3. 点击「两点取区」，依次单击画布矩形的两个对角点；也可先在画布选线，再点击「读取选中」。识别完成后，插件会在画布中选中对应目标。
4. 输入目标中心距，选择 mil 或 mm，并按需开启「兼容模式」。
5. 选择「直接调整」或「推挤走线」。推挤避让净距默认使用「PCB规则」，也可切换为「手动」输入。
6. 点击「应用」，查看状态栏中的处理结果。再次调整时，重新取区或读取选中走线。

两点取区须在 30 秒内完成，矩形宽高均至少为 10 mil，再次点击按钮可取消。区域与线宽相交即命中，选取整个直线图元，不在矩形边界裁断。

切换调整范围或铜层后，需要重新读取目标。自动识别遇到多个铜层都有目标时，会提示手动指定；应用时使用读取时确定的铜层。

## 参数说明

长度参数默认使用 mil，可切换为 mm，切换单位时会换算现有数值。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 取区范围 | 独立线段 | 只调整命中的平行直线；选择「完整走线」则沿连接关系扩展路径。 |
| 铜层 | 自动识别 | 按目标导线所属图层识别，支持顶层、底层及内层，也可手动指定。 |
| 布线模型 | 推挤走线 | 尝试移动周围冲突走线；「直接调整」只联动目标及必要连接段，不自动避让其他铜对象。 |
| 中心距 | 10 mil | 相邻主体的目标中心线距离，必须大于 0；固定端点附近的过渡段不保证等距。 |
| 单位 | mil | 可切换为 mm，中心距和手动避让净距使用相同单位。 |
| 推挤避让净距 | PCB规则 | 读取后显示导线间净距或范围；焊盘、过孔、板边分别使用对应规则。切换到手动时初始为 6 mil，可自行修改。仅推挤模式使用。 |
| 兼容模式 | 关闭 | 关闭时严格等距；开启后只展开间距不足的并行区域，不将已满足的独立区域压缩至目标值。 |
